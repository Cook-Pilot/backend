# 과일갈비찜 단계 이미지 업스케일

## 무엇을 바꿨는가

운영 레시피 `과일갈비찜`의 단계 이미지 6장은 너비가 모두 181px라 확대 시
재료와 조리 상태를 확인하기 어려웠다. 대표 이미지는 이번 교체 대상에서 제외했다.

GPT 이미지 편집으로 원본의 구도, 재료 종류와 수량, 용기, 익힘 정도를 유지해
복원한 뒤 1280px 너비 JPEG로 최적화하고 운영 S3에 업로드했다.

## 핵심 결정

- 생성 유형은 `precise-object-edit`으로 제한했다.
- 각 단계가 핏물 제거, 홍고추 볶기, 생갈비 투입, 양념장 준비, 과일·채소 손질,
  갈비 졸이기로 명확히 구분되도록 원본 장면을 고정했다.
- 5단계의 오른쪽 아래 재료가 생강처럼 보인 1차 결과는 밤 조각으로 한 번 교정했다.
- 새 파일은 기존 파일을 덮어쓰지 않고 별도 S3 객체로 저장했다.
- 반복 가능 마이그레이션은 단계 ID, 레시피 ID, 기존 URL이 모두 일치할 때만 갱신한다.

## 알려진 약점과 후속

- 181px 원본에서 식별할 수 없는 미세 질감은 생성 모델이 추정한 값이다.
- 운영 반영 후 실제 앱에서 크롭, 단계 간 연속성, 로딩 속도를 확인해야 한다.
- S3 객체는 기존 리뷰 사진 업로드 경로를 재사용했다.
